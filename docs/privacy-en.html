1. Summary

MrCards does not collect, transmit or share personal data. Everything stays on-device via SharedPreferences (mrcards.v1, mrcards.settings.v1, mrcards.onboarding.v1; read fallback flashcards.v1). No internet, analytics, ads or third-party SDKs.

2. Data processed & purpose

  • Decks & questions you create.
  • Progress: streaks, XP, level, correct/incorrect, spaced-repetition intervals, last 50 sessions.
  • Profile: name (2-30), optional age 5-120, gender, avatar, achievements.
  • Settings: theme, language (es/en/pt/fr/de/zh), sounds/haptics/animations, daily reminder time (local).

Purpose: provide offline study functionality. Legal basis: performance of contract / consent.

3. Permissions & security

Release build requests no INTERNET, camera, microphone, location or storage ( INTERNET only in debug/profile). Data encrypted at rest by OS.

4. Retention

Kept locally until you delete via Settings → Data → Delete all or uninstall (OS wipes sandbox).

5. User rights

Access, rectify, delete and portability directly in app (edit/delete decks/questions/profile, Export JSON, Delete all). Contact jabh2016@gmail.com.

6. Children

Suitable for all ages. No data collected from children, no account required.
