Política de Privacidad — MrCards

Última actualización: 11 de septiembre de 2026
App: MrCards — com.mrcards.app — v1.0.0 — 100% offline
Responsable: MrCards App (Jabh2) — Contacto: jabh2016@gmail.com

1. Resumen

MrCards no recopila, no transmite y no comparte datos personales. Todo el contenido permanece en tu dispositivo mediante SharedPreferences local (mrcards.v1, mrcards.settings.v1, mrcards.onboarding.v1; compatibilidad de lectura con flashcards.v1 heredado). No usamos internet, analítica, publicidad, ni SDK de terceros.

2. Datos tratados y finalidad

  • Mazos y preguntas que tú creas (títulos, descripciones, prompts/respuestas, opciones, pistas, pares).
  • Progreso: rachas, XP, nivel, intentos correctos/incorrectos, intervalos de repetición espaciada, 50 últimas sesiones.
  • Perfil: nombre (2-30), edad opcional 5-120, género, avatar emoji, logros.
  • Ajustes: tema, idioma (es/en/pt/fr/de/zh), sonidos/vibración/animaciones, recordatorio diario (hora local).

Finalidad: prestar la funcionalidad de estudio offline. Base jurídica: ejecución del contrato / consentimiento al usar la app.

3. Permisos y seguridad

La build release no solicita INTERNET, micrófono, ubicación, contactos ni almacenamiento externo (solo INTERNET en profile/debug para desarrollo). Para preguntas con foto puedes usar la galería (selector del sistema, sin permiso) o la cámara (permiso CAMERA solo al tomar la foto). Las fotos se guardan únicamente en el almacenamiento privado de la app en tu dispositivo. Datos cifrados en reposo por Android/iOS.

4. Conservación

Los datos se conservan localmente hasta que los borres en Configuración → Datos → Eliminar todo o desinstales la app (Android/iOS borra el sandbox al desinstalar).

5. Derechos del usuario

Puedes ejercer acceso, rectificación, supresión y portabilidad directamente en la app: edita o borra mazos/preguntas, perfil, o usa Exportar JSON para portar y Eliminar todo para suprimir. Si necesitas ayuda, escribe a jabh2016@gmail.com.

6. Menores

Apta para todas las edades. No recopilamos datos de menores ni requerimos cuenta.

7. Cambios

Cualquier cambio se publicará aquí con nueva fecha de actualización.
